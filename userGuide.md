# JB Eletronic - Guia do Usuário

## Visão Geral

**JB Eletronic** é uma plataforma de e-commerce completa para venda de eletrônicos, construída com tecnologias modernas e escaláveis.

**Acesso:** Público (com autenticação para compras)

---

## Powered by Manus

**Stack Tecnológico:**

- **Frontend:** React 19 + TypeScript + Tailwind CSS 4 + shadcn/ui
- **Backend:** Express.js + tRPC 11 + Node.js
- **Banco de Dados:** PostgreSQL (via Drizzle ORM)
- **Autenticação:** Manus OAuth + JWT
- **Armazenamento:** S3 para imagens de produtos
- **Deployment:** Auto-scaling infrastructure com global CDN

## Usando Sua Loja

### Para Clientes

**Navegação Principal:**
1. Clique em "Catálogo" para explorar todos os produtos
2. Use a barra de busca para encontrar produtos específicos
3. Filtre por categoria para refinar sua busca

**Comprando um Produto:**
1. Clique no produto desejado para ver detalhes
2. Escolha a quantidade usando os botões "−" e "+"
3. Clique em "Adicionar ao Carrinho"
4. Clique no ícone do carrinho (canto superior direito)
5. Revise seus itens e clique em "Ir para Checkout"
6. Preencha seu endereço de entrega
7. Clique em "Confirmar Pedido"

**Acompanhando Pedidos:**
1. Clique em "Meus Pedidos" (após fazer login)
2. Veja o status de cada pedido
3. Clique no pedido para ver detalhes completos
4. Cancele pedidos com status "Pendente" se necessário

### Para Administradores

**Acessando o Painel:**
1. Clique em "Admin" na navegação principal
2. Você verá o dashboard com estatísticas de vendas

**Dashboard Admin:**
- **Total de Vendas:** Receita total em reais
- **Ticket Médio:** Valor médio por pedido
- **Produtos com Baixo Estoque:** Lista de itens críticos

**Gerenciando Produtos:**
1. Clique em "Gerenciar Produtos" no dashboard
2. Veja todos os produtos com preço e estoque
3. Use a busca para encontrar produtos específicos
4. Edite ou delete produtos conforme necessário

## Gerenciando Sua Loja

### Management UI (Painel de Controle)

Acesse as configurações através do ícone de menu no canto superior direito:

**Settings (Configurações):**
- Altere o nome e logo da loja
- Configure visibilidade pública/privada
- Gerencie segredos e variáveis de ambiente

**Database (Banco de Dados):**
- Visualize e gerencie dados de produtos, pedidos e usuários
- Execute queries SQL diretamente
- Faça backup dos dados

**Dashboard (Painel):**
- Monitore estatísticas em tempo real
- Veja análise de visitantes
- Acompanhe conversões

**Domains (Domínios):**
- Configure domínio customizado
- Gerencie certificados SSL
